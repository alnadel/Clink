## 1. PWA (`vite-plugin-pwa`, `generateSW` mode)

In `apps/web/vite.config.ts`:

```ts
import { VitePWA } from 'vite-plugin-pwa';

VitePWA({
  registerType: 'autoUpdate',
  injectRegister: false,              // we register in src/platform/sw.ts with workbox-window
  manifest: {
    name: 'Clink', short_name: 'Clink', id: '/', start_url: '/', scope: '/',
    display: 'standalone', orientation: 'portrait',
    background_color: '#0f172a', theme_color: '#0f172a',
    icons: [
      { src: '/icons/icon-192.png', sizes: '192x192', type: 'image/png' },
      { src: '/icons/icon-512.png', sizes: '512x512', type: 'image/png' },
      { src: '/icons/icon-maskable-512.png', sizes: '512x512', type: 'image/png', purpose: 'maskable' },
    ],
  },
  workbox: {
    globPatterns: ['**/*.{js,css,html,woff2,svg,png,webp}', 'audio/glass/*', 'audio/sfx/*', 'audio/silence.mp3', 'art/w1/**'],
    globIgnores: ['art/w2/**', 'art/w3/**', 'content/**', 'config.json'],
    navigateFallback: '/index.html',
    navigateFallbackDenylist: [/^\/content\//, /^\/config\.json$/, /^\/audio\//, /^\/art\//],
    runtimeCaching: [
      { urlPattern: ({ url }) => url.pathname === '/config.json' || url.pathname === '/content/manifest.json',
        handler: 'NetworkFirst', options: { cacheName: 'clink-live', networkTimeoutSeconds: 3 } },
      { urlPattern: ({ url }) => url.pathname.startsWith('/content/packs/'),
        handler: 'CacheFirst', options: { cacheName: 'clink-packs', expiration: { maxEntries: 40 } } },
      { urlPattern: ({ url }) => url.pathname.startsWith('/art/') || url.pathname.startsWith('/audio/'),
        handler: 'CacheFirst', options: { cacheName: 'clink-assets', expiration: { maxEntries: 200 } } },
    ],
  },
})
```

`src/platform/sw.ts`:
- `registerServiceWorker()` uses `new Workbox('/sw.js')` from `workbox-window`, only in
  production builds.
- When a new version activates, it shows a small toast, `t('app.updated')`, and does **not**
  force a reload in the middle of a level.

**Offline (FR-35):**
- After the first load, the precache holds the app, World 1 art and all audio.
- `content.warm()` (05 §12) fetches every pack and the art for Worlds 2–3 in the background,
  so every level is playable offline once it unlocks.
- The E2E offline test loads the app, waits for `warm()`, sets the browser offline, reloads,
  and plays a level.

## 3. Headers (`public/_headers`, Netlify and Cloudflare Pages format)

```
/*
  Content-Security-Policy: default-src 'self'; script-src 'self'; style-src 'self' 'unsafe-inline'; img-src 'self' data: blob:; media-src 'self' blob:; font-src 'self'; connect-src 'self' ANALYTICS_ORIGINS; worker-src 'self' blob:; manifest-src 'self'; base-uri 'self'; form-action 'none'; frame-ancestors 'none'; object-src 'none'
  Strict-Transport-Security: max-age=31536000; includeSubDomains
  X-Content-Type-Options: nosniff
  Referrer-Policy: strict-origin-when-cross-origin
  Permissions-Policy: camera=(), microphone=(), geolocation=(), payment=()
/index.html
  Cache-Control: no-cache
/sw.js
  Cache-Control: no-cache
/config.json
  Cache-Control: public, max-age=300
/content/manifest.json
  Cache-Control: public, max-age=300
/content/packs/*
  Cache-Control: public, max-age=31536000, immutable
/assets/*
  Cache-Control: public, max-age=31536000, immutable
```

`ANALYTICS_ORIGINS` is replaced with the analytics and error-reporting origins once DEC-7
settles them (09 §2). Until then it is empty. **PixiJS needs `import 'pixi.js/unsafe-eval'`
to run under this CSP.** Despite its name, that module removes Pixi's use of `eval`.
`style-src 'unsafe-inline'` is needed for Preact inline styles.

An E2E test fetches `/` from `vite preview` and asserts these headers. `vite preview` does not
read `_headers`, so the test parses the file and checks its content, and the deploy smoke test
checks the live site.

## 5. Deploy

- **Hosting:** Cloudflare Pages or Netlify (D30), with the build command
  `pnpm install --frozen-lockfile && pnpm build` and output `apps/web/dist`.
- **Previews:** every pull request gets a preview URL. `main` deploys to staging, and a
  tagged release deploys to production.
- **The production origin is chosen once and never changes after soft launch.** Saves and
  installs are tied to it (implementation-plan §2.4).
- **Source maps:** built as `hidden` (`build.sourcemap: 'hidden'`), uploaded to the error
  tracker in the release job, and **deleted from `dist/` before upload to the host**.

## 6. Budgets (checked in CI)

| Budget | Check |
|---|---|
| NFR-02: first download 3 MB or less compressed | `scripts/check-size.mjs` gzips every precached file (the Workbox precache manifest in `dist/sw.js`) and fails above 3,000,000 bytes. JS alone should stay under 350 KB gzip. |
| NFR-01: first playable level in 3 s or less on throttled Fast 4G | Lighthouse CI on the preview URL, mobile preset. Time to Interactive of 3 s or less is a proxy. The real check is on the budget reference phone every week. |
| NFR-03: 60 fps | A dev-only FPS overlay (`?fps=1`). Checked weekly on devices. |

## 7. Browsers (NFR-06)

iOS Safari 16.4 or later (in the browser and installed), Chrome for Android, Samsung Internet
(current and previous major versions), and current desktop Chrome, Safari, Edge and Firefox.
The Vite build target is `['es2022', 'safari16.4']`. Playwright runs Chromium and WebKit in
CI.
