# 10 · i18n and accessibility

Requirements: FR-28 to FR-31, NFR-09, NFR-13. Decisions D7, D20, D21.

## 1. Strings (`i18n/`)

- `i18n/en.json` and `i18n/ar.json`: flat objects of `"screen.element": "text"`, bundled
  with the app. Example: `"play.moves": "Moves {moves} · Par {par}"`.
- `createI18n(setting: LanguageSetting): I18n` (contract in `i18n/types.ts`):
  - `system`: `ar` if `navigator.language` starts with `ar`, otherwise `en`;
  - `t(key, vars)`: look up the locale, fall back to `en`, then to the key itself (logged
    once in development). Replace `{name}` with `String(vars[name])`.
  - Numbers inside strings are formatted with `Intl.NumberFormat(locale)`. Arabic uses
    Western digits for now; revisit with DEC-1.
- **Key naming:** `app.*`, `home.*`, `map.*`, `play.*`, `solve.*`, `daily.*`, `songbook.*`,
  `settings.*`, `guide.*`, `survey.*`, `install.*`, `privacy.*`, `a11y.*` (screen-reader
  labels).
- **No string literals in UI markup.** Every visible text and every `aria-label` goes through
  `t()`. A unit test asserts that `en.json` and `ar.json` have the same keys once Arabic
  ships (FR-31).
- Tune titles and origins come from `manifest.tunes`. They are not translated for the MVP.

## 2. Right-to-left (FR-31)

- `document.documentElement.lang = locale` and `dir = 'rtl'` for Arabic.
- CSS uses **logical properties only**: `margin-inline-start`, `padding-inline`,
  `inset-inline-end`, `text-align: start`. Physical `left` and `right` are not allowed
  outside `board/`.
- **The board does not mirror.** Its container has `dir="ltr"`, and Pixi draws left to right
  whatever the page direction. The glasses and melody bar keep their order, and the HUD
  mirrors.
- Directional icons (back arrow) flip with `:dir(rtl) { transform: scaleX(-1) }`.
- Fonts: the system UI font stack, plus `Noto Sans Arabic` (a woff2 subset) for Arabic.

## 3. Note colours, glyphs and labels (FR-28, FR-29, D7, D20)

`theme/notes.ts` exports `noteStyle(pitchClass: number, octave: number): { color: string;
glyph: GlyphShape; hollow: boolean; octaveDots: number }`:

| Pitch class | Colour | Glyph | Hollow |
|---|---|---|---|
| C | `#FF5A5F` | circle | no |
| C# | `#FF8A8D` | circle | yes |
| D | `#FF9F1C` | triangle | no |
| D# | `#FFBE66` | triangle | yes |
| E | `#FFE14D` | square | no |
| F | `#6BD968` | pentagon | no |
| F# | `#9BE89A` | pentagon | yes |
| G | `#2EC4B6` | diamond | no |
| G# | `#7ADCD3` | diamond | yes |
| A | `#4EA8FF` | star | no |
| A# | `#8CC5FF` | star | yes |
| B | `#B388FF` | hexagon | no |

- `octaveDots = octave - 4`. Positive values draw that many dots above the glyph and negative
  values draw them below, so C3 has one dot below, C4 none and C5 one dot above.
- Because every note in C3–A5 gets a unique glyph, hollow and dots combination, **every level
  is solvable from a grayscale screenshot** (FR-29). The Gate 3 review checks screenshots
  with `filter: grayscale(1)`.
- The artist may replace colours and shapes (D7), but the combination must stay unique per
  note.

**Labels (FR-28):**
- `letters`: the position's `name` without the octave, with `#` shown as `♯`;
- `solfege`: fixed-do `do re mi fa sol la ti`, with `♯` for sharps;
- `none`: nothing.

Labels switch live via `board.setOptions`, and also update the melody bar.

## 4. Reduced motion (FR-30, D21)

`reducedMotion = setting === 'on' || (setting === 'system' &&
matchMedia('(prefers-reduced-motion: reduce)').matches)`. Listen for `change` on that media
query. When it is on, the board uses the alternatives in 05 §4.1 (fades, no tilt, no lift,
no shake), and DOM transitions are limited to opacity.

## 5. Accessibility checklist (NFR-09, WCAG 2.2 AA)

- Every interactive DOM element is a real `<button>`, `<a>` or `<input>` with a visible
  focus ring, and at least 44 × 44 CSS px.
- Text contrast is at least 4.5:1, and 3:1 for large text and icons, against `--bg`.
- Modals trap focus, close on Escape and return focus to their trigger.
- Playwright runs `@axe-core/playwright` on Home, Map, Play, Solve card, Settings and
  Songbook, with no serious or critical violations. Add `@axe-core/playwright` in the E2E
  issue.
- **Board:** every level is playable without sound (rule 4 fill marks) and without colour
  (§3). On desktop, keys 1–5 tap glasses 1–5, F and S tap the faucet and sink, Space plays
  the melody, and Z undoes. A visually hidden live region announces moves:
  `t('a11y.moved', { from, to, moves })`.
